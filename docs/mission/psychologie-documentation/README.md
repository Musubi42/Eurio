## Convention

- Un fichier `NN-slug.md` par sujet (numérotation = ordre de production, pas de priorité).
- En-tête de chaque doc : question de recherche, date, sources principales.
- Chaque affirmation porte sa **source** (lien). On distingue *fait sourcé* / *interprétation*.
- Fin de doc : **« Ce qu'on en retient pour Eurio »** → ce qui remonte dans le doc vivant.

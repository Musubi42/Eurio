# Mission — Marketplace (North Star)

> Index : [`README.md`](./README.md) · Stratégie : [`product-strategy.md`](./product-strategy.md)

## Objectif

L'**étoile polaire** : acheter / vendre / troquer des pièces **dans l'app**, Eurio prenant
une **commission** sur la transaction (modèle Leboncoin). Monétisation forte qui **clôt la
boucle** de collection (compléter ↔ écouler).

## Pourquoi c'est le North Star, pas le départ

- **Pas de cold-start frontal.** La liquidité (offre + demande) est **construite par les
  paliers d'avant** : la Valorisation crée des **wishlists** (« ce qui me manque ») et des
  items **« à vendre »** ; la Croissance amène la **base d'utilisateurs**. Quand la
  marketplace ouvre, les deux faces existent déjà.
- **Attaquer une marketplace en premier = le piège** : deux faces vides + fardeau paiement.

## Ce qui est volontairement différé / ouvert

- **Paiements / KYC / escrow / fraude / régulation** : lourds, hors scope tant que la base
  n'est pas là. **Peut-être opérés par un partenaire** spécialisé (pas forcément nous).
- Modèle exact de transaction (achat direct, enchères, troc), niveau de commission, gestion
  litiges, expédition/authentification : à trancher le moment venu.

## Principe

C'est une **étoile polaire**, pas une promesse. **Si on n'y arrive jamais mais qu'on a
construit une belle app de collection aboutie (scan + coffre + sets + carte + valorisation),
c'est déjà une réussite.** La marketplace est le sommet de l'échelle, pas son prérequis.

## Pré-requis (avant d'en reparler sérieusement)

- App + scan debout (P0), valorisation + wishlists/«à vendre» (P1), base d'utilisateurs (Croissance).
- Une réponse claire sur **qui opère les paiements** (nous vs partenaire).

## Done quand

Transactions in-app avec commission, confiance et paiement résolus. *(Définition lointaine,
à préciser quand on s'en approche.)*

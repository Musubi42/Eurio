Ce que la page ne fait pas

Décision du PO (2026-08-23) : pas de surface spécialisée. Pas de mode « session », pas de refonte de la pêche, pas d'écran « émission commune ». Le tri, le filtrage et le choix se font ici ; trancher se fait dans les pages de review qui existent déjà.

Chaque geste est donc un lien qui porte son réglage : /review/peche?class=<id>&need=1, plus &pays=tous quand la ligne dit « pays désarmé ». Sans ça, la page annoncerait 66 candidats au-dessus d'une file qui en sert 0.

Toutes les valeurs de cette maquette viennent de shared.class_need.all_needs(anchors_kind='2eur_all', encoder_version='dinov2-vitl14') sur ml/state/eurio.replica.db, banque a55e6594da3247ec80bc609f93342f51 (built_at 2026-08-22 18:06:22). Elles bougent à chaque rebuild : relancer la requête, ne pas recopier le nombre.
